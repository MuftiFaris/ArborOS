## Translation Infrastructure

### .ts Files (Qt Translation Source Files)

Format: `arbor_[language].ts`

```xml
<?xml version="1.0" encoding="utf-8"?>
<!DOCTYPE TS>
<TS version="2.1" language="de_DE">
    <context>
        <name>Arbor::FileManager::FileManager</name>
        <message>
            <source>&amp;File</source>
            <translation>&amp;Datei</translation>
        </message>
        <message>
            <source>Cu&amp;t</source>
            <translation>Aus&amp;schneiden</translation>
        </message>
    </context>
</TS>
```

### .qm Files (Qt Compiled Translation Files)

Generated from .ts files using `lrelease`:

```bash
lrelease arbor_de.ts -qm arbor_de.qm
lrelease arbor_fr.ts -qm arbor_fr.qm
lrelease arbor_es.ts -qm arbor_es.qm
lrelease arbor_ja.ts -qm arbor_ja.qm
lrelease arbor_zh.ts -qm arbor_zh.qm
lrelease arbor_ru.ts -qm arbor_ru.qm
```

### Extraction

Extract translatable strings for translation:

```bash
# Generate .ts files for each language
lupdate Code/applications -ts Code/applications/translations/arbor_de.ts
lupdate Code/applications -ts Code/applications/translations/arbor_fr.ts
lupdate Code/applications -ts Code/applications/translations/arbor_es.ts
lupdate Code/applications -ts Code/applications/translations/arbor_ja.ts
lupdate Code/applications -ts Code/applications/translations/arbor_zh.ts
lupdate Code/applications -ts Code/applications/translations/arbor_ru.ts
```

## Usage in Code

### Marking Strings for Translation

```cpp
// Use tr() macro for all user-visible strings
QString label = tr("Install");
QString message = tr("File copied to clipboard");

// Context-specific translation
QString menuItem = tr("File", "Menu bar");
QString statusBar = tr("File", "Status message");

// Plural forms
QString items = tr("%n item(s)", "File count", fileCount);

// Format strings with parameters
QString formatted = tr("Copied %1 files").arg(count);
```

### Loading Translations at Runtime

```cpp
#include "LocalizationManager.h"

using namespace Arbor::Localization;

// In main():
LocalizationManager::instance()->setApplicationLanguage("de");

// Language change callback
connect(LocalizationManager::instance(), &LocalizationManager::languageChanged,
        this, [this](const QString &lang) {
    retranslateUI();  // Re-translate all UI strings
});
```

### Date/Time Localization

```cpp
QDate date = QDate::currentDate();
QString formatted = LocalizationManager::instance()->formatDate(date);
// Outputs: "1. September 2026" (German)
// Outputs: "1 September 2026" (English)

double amount = 1234.56;
QString currency = LocalizationManager::instance()->formatCurrency(amount);
// Outputs: "1.234,56 EUR" (German)
// Outputs: "$1,234.56" (English)
```

## Translator Notes

### German (Deutsch)
- Use formal "Sie" (vous in French) for UI text
- Menu items use short, concise terms
- Special characters: ä, ö, ü, ß

### French (Français)
- Use formal "vous" in instructions
- Maintain grammatical gender and number
- Common abbreviations: M. (Monsieur), Mme (Madame)

### Spanish (Español)
- Use "vosotros" form for informal plural
- Accented characters: á, é, í, ó, ú, ü, ñ
- Use "usted" for formal address

### Japanese (日本語)
- Use polite form (敬語, keigo)
- Consider context for formal/informal
- Right-to-left reading not needed (horizontal layout)

### Chinese Simplified (中文)
- Use Simplified characters (not Traditional)
- Context-aware capitalization doesn't apply
- Number formatting: 1,234 or 1234 depending on context

### Russian (Русский)
- Maintain grammatical case agreement
- Special characters: ё is important (not just е)
- Transliteration: "Arbor" → "Арбор"

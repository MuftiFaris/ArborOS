# ArborOS Privacy & User Control Guide

## Overview

ArborOS puts you in control of your privacy. This guide explains how to use privacy features.

## Managing App Permissions

### Microphone Access
- Go to Settings → Privacy → Microphone
- See which apps have microphone permission
- Grant, deny, or ask each time

### Camera Access
- Settings → Privacy → Camera
- Similar to microphone control
- Visual indicator shows when camera is active

### File Access
- Settings → Privacy → Files
- Choose which directories apps can access
- Default: Apps can only access their own data directory

## Privacy Dashboard

Open Privacy Dashboard to:
- See your privacy score (0-100)
- View recent permission requests
- Check app access history
- Review complete audit trail

## Global Settings

Disable all microphone/camera access system-wide:
- Settings → Privacy → Global Settings
- Microphone: Toggle on/off
- Camera: Toggle on/off
- Applies even if apps request permission

## Understanding the Audit Trail

The audit trail records every permission request and usage:
- Timestamp of each event
- Which app made the request
- What permission was requested
- User decision (Allow/Deny/Ask)

View complete history in Privacy Dashboard.

## Best Practices

1. Review unknown app permissions
2. Deny unnecessary permissions
3. Use "Ask every time" for sensitive apps
4. Check Privacy Dashboard weekly
5. Enable global restrictions for unused sensors

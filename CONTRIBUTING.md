# Contributing to ArborOS

Thank you for your interest in contributing to ArborOS!

## Project Status

ArborOS is currently in **early development** (pre-alpha). We are actively working through the implementation phases.

**Current Phase:** Phase 4 - Installer (Configuration)  
**Completed:** Phases 1-3 (Repository, Base System, Hardware Support)

## How to Contribute

### Reporting Issues

Found a bug or have a suggestion? Please open an issue with:
- Clear description
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- System information (for hardware-related issues)

### Code Contributions

**Not accepting code contributions yet** as the architecture is still being established. This will open up in later phases.

### Testing

We welcome testing reports! If you've tested ArborOS:
1. Boot the latest ISO
2. Run hardware detection: `sudo arbor-hwinfo`
3. Document your findings
4. Submit as an issue with "Testing Report" label

### Documentation

Documentation improvements are welcome:
- Typo fixes
- Clarifications
- Better explanations
- Additional examples

## Development Setup

See `Documentation/07-Implementation/` for phase-specific implementation guides.

**Building ISO:**
- Requires: Linux VM (Ubuntu/Fedora), Docker
- See: `Documentation/.../Phase 3 - Hardware Support/README.md`

## Code Style

- Shell scripts: Follow standard bash conventions
- Documentation: Markdown, clear headers, code blocks
- Commits: Descriptive messages, reference issues/phases

## Questions?

Open an issue with the "question" label.
